# Módulo Songs

Este módulo gestiona todas las operaciones relacionadas con las canciones:
- Visualización en lista y detalle.
- Creación, edición y eliminación de canciones.
- Validación de formularios y gestión de relaciones con artistas.

Para más información y detalles sobre la implementación, consulta la documentación completa en [docs/songs.md](../../../../docs/songs.md).
